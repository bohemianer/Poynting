# 电磁场与高频信号传输 3D 可视化物理实验室 (EM Signal Propagation Lab)

直观观察与交互探索高频传输线中的电磁波传播、坡印廷能量流、集肤效应与差分共模抑制物理机理。

---

## 🌟 核心特性与三大演示模式

本可视化实验室包含三大交互模式，针对传统电路理论与高频电磁场理论的底层差异进行 1:1 物理级还原：

### 1. 单端高速信号 (微带线 Microstrip TEM / Quasi-TEM 波)
* **坡印廷能量流 $\mathbf{S} = \mathbf{E} \times \mathbf{H}$ 粒子推进**：
  * **物理真相**：信号能量**并不是在铜线内部跑**，而是在**信号走线与参考地平面之间的绝缘介质（FR-4 / PTFE）中以电磁波形式向前冲刺**！
  * 铜线为良导体，内部内电场 $E \approx 0$，因此铜导线内部能流 $S \approx 0$。铜线充当的是电磁波的“引路波导与物理边界”。
* **电场线 $\mathbf{E}$ 矢量**：
  * 正电荷聚集在走线下表面，负电荷聚集在地平面上表面。
  * 垂直贯穿介质基底直插地平面，并在两侧呈现优雅的弧形边缘电场（Fringing Fields）。
* **磁场线 $\mathbf{H}$ 闭合环**：
  * 根据高斯磁定律 $\nabla \cdot \mathbf{B} = 0$，磁力线无起点亦无终点，环绕信号走线形成闭合椭圆回环。
* **高频返回电流自约束（$\min \omega L$）**：
  * 地平面上的返回电流**不再四处扩散**，而是死死吸附在信号走线正下方的狭窄狭带内，以最小回路面积换取最小回路电感。
* **实时特征阻抗仪表盘**：
  * 基于 IPC-2141 / Wheeler 权威微带线公式，实时计算特征阻抗 $Z_0$（如 54.4 $\Omega$）、有效介电常数 $\varepsilon_{eff}$、宽厚比 $W/h$、相位传播速度 $v_p$（如 $0.55c$）及传输时延 $T_{pd}$。

---

### 2. 高速差分信号 (差分对 Differential Pair / 奇模传输)
* **横向差模电场自锁定**：
  * Trace(+) 与 Trace(-) 分布大小相等、极性相反的电荷，强烈的横向差分电场直接在两根走线之间相互终止，极大地减少了对外界及地平面的能量泄露。
* **远场磁场自抵消与极低 EMI 辐射**：
  * 两根走线中反向流动的高频电流激发的磁力环，在两线之间同相叠加强化，而在外侧远场空间相互反向抵消，几乎不向外太空辐射电磁波。
* **共模噪声入侵与实时对消（CMRR）示波器**：
  * 支持交互式**注入共模噪声（EMI）**：可调节空间噪声电压幅度。
  * 示波器实时显示：
    * **Trace(+)**：正相信号 + 噪声畸变波形；
    * **Trace(-)**：反相信号 + 同极性噪声畸变波形；
    * **差分输出 $V_{diff} = (V_+ - V_-) / 2$**：相减瞬间共模噪声完全对消，输出极其纯净的原生正弦波！
* **差分几何与阻抗**：
  * 提供差分间距 $S$ 滑块，实时计算差分阻抗 $Z_{diff}$ 与双线耦合度 $k$。

---

### 3. 单端低速信号 (集总参数模型 / 传统电路理论对比)
* **电子漂移视角**：
  * 低频下信号波长远大于导线物理长度（$\lambda \gg L$）。
  * 铜导线内部电子做剧烈无规则布朗热运动，伴随微米每秒级的缓慢宏观漂移速度。
* **地平面低频欧姆扩散**：
  * 返回电流走欧姆直流电阻最小路径（$\min R$），在整个地平面大面积呈扇形均匀扩散漫延。
* **示波器同相**：
  * 驱动端与接收端瞬间同相，忽略空间行波时延。

## 🚀 启动与使用方式

项目已完全内置离线版 `three.min.js` 与 `OrbitControls.js`，无需安装任何 Node.js 依赖或外部网络：

### 方法 1：直接双击打开
直接使用任何现代浏览器（Chrome、Edge、Safari、Firefox）双击打开项目中的 `index.html` 即可完整运行！

### 方法 2：使用本地简易 HTTP 服务器（推荐）
在项目根目录下运行：
```bash
python3 -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`

支持通过 URL 参数直接定位模式：
- `http://localhost:8080/?mode=single-high` (单端高速微带线)
- `http://localhost:8080/?mode=differential` (高速差分对)
- `http://localhost:8080/?mode=single-low` (单端低速集总参数)

## 🎮 交互控制说明

1. **3D 视角交互**：
   - **鼠标左键拖拽**：360° 旋转 3D 视角；
   - **鼠标滚轮**：缩放视角，推近观察微带线截面；
   - **鼠标右键拖拽**：平移视角；
   - **视角预设按钮**：
     - `3D 透视`：经典立体俯瞰；
     - `正截面 (E/H环)`：沿导线纵轴直接观察截面电磁力线架构；
     - `侧视走廊`：观察能量粒子沿介质走廊的流速与波前；
     - `俯视平面`：俯视对比高频自约束通道与低频扩散回流；
     - `视角复位`：一键回归最佳观测机位。
2. **图层与物理量开关**：
   - `电场线 E`：显示/隐藏垂直与侧边弯曲电场；
   - `磁场环 H`：显示/隐藏环绕走线的闭合安培磁环；
   - `能量流 S 粒子`：显示/隐藏介质层中高速推进的坡印廷光粒子流；
   - `地平面回流`：显示/隐藏地平面电流流向与聚集路径；
   - `透视介质 (FR-4)`：在半透明水晶基材与实体板之间切换；
   - `暂停/继续动画`：定格观察波前切片与空间粒子分布。
3. **参数调节滑块**：
   - **走线宽度 $W$ (0.4 ~ 4.0 mm)**；
   - **介质厚度 $h$ (0.4 ~ 3.0 mm)**；
   - **差分间距 $S$ (0.3 ~ 3.5 mm)**（差分模式）；
   - **基材材质 $\varepsilon_r$**（FR-4 4.4, Rogers RO4350B 3.48, PTFE 2.1, 空气介质 1.0）；
   - **电磁波传播速度**（0.2x ~ 3.0x 动画变速）。
4. **截面剖视与深度解析**：
   - 点击右上角 `截面剖视`：展开实时的 2D 电磁横截面切片示意图；
   - 点击右上角 `物理深度解析`：弹出麦克斯韦方程组、坡印廷矢量定理、高斯磁定律、高频集肤效应与差分抗噪详细公式拆解。
